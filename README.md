# 🎮 Game Site

Интерактивный одностраничный сайт-приглашение поиграть вместе. Пользователь выбирает игру, после чего выбор отправляется через Discord Webhook, а на экране появляется подтверждение.

## ✨ Возможности

- 🎮 Игровой дизайн
- 🎲 Анимированный фон
- 😄 Кнопка «Нет», убегающая от курсора
- 📋 Выбор любимой игры
- 📨 Отправка выбора в Discord
- 📱 Адаптивный интерфейс

## 🚀 Демо

https://george5556.github.io/game-site/

## 🛠️ Технологии

- HTML5
- CSS3
- JavaScript
- Discord Webhooks

## 📦 Запуск

```bash
git clone https://github.com/George5556/game-site.git
cd game-site
```

Откройте `index.html` в браузере.
