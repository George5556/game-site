# 🎮 Game Site

Небольшой интерактивный веб-сайт с игровым оформлением, созданный как приглашение поиграть вместе.

## Возможности

- Анимированный фон с игровыми иконками
- Интерактивная кнопка «Нет», убегающая от курсора
- Выбор одной из предложенных игр
- Отправка выбранной игры через Discord Webhook
- Финальный экран с подтверждением выбора
- Адаптивный интерфейс

## Технологии

- HTML5
- CSS3
- JavaScript (Vanilla)
- Discord Webhooks

## Запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/George5556/game-site.git
```

2. Перейдите в папку проекта:

```bash
cd game-site
```

3. Откройте `index.html` в любом современном браузере.

## Структура проекта

```
game-site/
├── index.html
└── README.md
```

## Как это работает

1. Пользователь отвечает на вопрос «Ты готов со мной поиграть?».
2. При выборе «Да» открывается список игр.
3. После выбора игры данные отправляются в Discord через Webhook.
4. Пользователь получает подтверждение отправки.
